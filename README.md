# Svar

> Minimal synced lyrics viewer written in Rust.

Just me learning Rust and trying out Ratatui.

## Keys

| Key | Action |
| :--- | :--- |
| `q` / `Ctrl+C` | Quit |
| `j` / `Down` | Scroll down |
| `k` / `Up` | Scroll up |
| `c` | Re-center live lyrics |
| `r` | Re-fetch lyrics |

## Run

```bash
cargo run
```
